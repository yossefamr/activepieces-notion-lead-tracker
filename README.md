# 🤖 Activepieces Notion Lead Tracker

An automated lead-tracking system built with **Activepieces**, **Webhooks**, and **Notion API**.

## ⚡️ Overview
This workflow automatically listens for incoming webhook payloads, processes lead details, and logs/updates records dynamically inside a Notion database with status notifications.

## 🛠️ Tech Stack
- **Automation Engine:** Activepieces
- **Trigger:** Custom Webhooks
- **Database:** Notion API
- **Scripting:** Node.js / JavaScript

## 🚀 Key Features
- Real-time lead logging via Webhooks
- Automated status updates in Notion
- Seamless error handling and execution logging
